题目来源：蓝桥杯第十七届省赛无忧班 编程36题——位移

解题思路：

直接将两个数据转换成二进制形式，然后去掉 b 两端的 0，若去掉 0 的 b 是 a 的子字符串，则可以判定 b 可以通过 a 左移和右移得到。

代码示例：

import sys

input = lambda: sys.stdin.readline().rstrip()
t = int(input())

for _ in range(t):
    a, b = map(int, input().split())
    a = bin(a).split('b')[1]
    b = bin(b).split('b')[1].strip('0')
    if b in a:
        print('Yes')
    else:
        print('No')

### 举例说明：
- **示例 1**：  
  a = 5 的二进制是 101，通过左移得到 1010（b = 10），b 的有效部分是 101，是 a 的子串 → 输出 Yes。  

- **示例 2**：  
  a = 4 的二进制是 100，通过左移得到 1000（b = 8），b 的有效部分是 1，是 a 的子串 → 输出 Yes。  

- **示例 3**：  
  a = 3 的二进制是 11，b = 5 的二进制是 101，b 的有效部分是 101，不是 a 的子串 → 输出 No。  

### 思路局限性：
如果题目中的位移是“带高位丢弃”的逻辑左移（比如 a = 128（10000000）左移后变成 0），这个思路可能需要补充 b = 0 的特殊情况（例如当 b = 0 时，判断 a 的二进制串全为 0 或能通过位移丢弃所有 1）。
